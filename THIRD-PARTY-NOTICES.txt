Windows, Microsoft Edge and other system marks
----------------------------------------------
HangAll runs on Windows and draws its own chrome in the style of Windows 11.
The documentation film under docs/ shows the application on a simulated
desktop: that desktop is drawn by HangAll's own rendering code for
illustration, and its taskbar app icons were captured from a local Windows
installation when the film was generated (scripts/make-film.ps1). The film
therefore shows Windows, Microsoft Edge and OneDrive icons and the Windows
logo as part of the simulated environment.

Windows, Microsoft Edge, OneDrive and the Windows logo are trademarks of
Microsoft Corporation. Their appearance in the documentation film is nominative
illustration of the environment HangAll runs in; HangAll is not affiliated
with, endorsed by or sponsored by Microsoft. No Microsoft artwork or icon file
is part of the application, its installer or its assets: at run time the
application reads icons from the machine it runs on and does not redistribute
them.
